# Water Guardians

Premium, mobile-first water conservation site with two clear paths:

- **Kids** — storybook, Leak Patrol, My Water Day, animated films
- **Adults** — 32 practical tips with pledges

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Add your videos

1. Drop MP4 files into `assets/videos/`
2. Match the names listed in `assets/videos/README.txt`, or update the `VIDEOS` array in `js/app.js`

## Stack

Plain HTML, CSS, and JavaScript — no build step.
